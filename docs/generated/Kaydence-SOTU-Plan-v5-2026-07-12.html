Plan of Attack v5 — unjam, then advance

Four stages. Stage A is operator-gated and blocks everything; do it first. Stages B–D are the build, resumed on a pipeline that can actually merge.

A

Unjam the pipeline

operator-gated · do first · unblocks all 17 PRs

  1. Fix CI billing durably. Decide the model (see decisions below): raise the cap and stop draft PRs from running the full 3-OS matrix, or make the repo public (free unlimited CI). The current pattern — 17 PRs × full 3-OS × macOS ×10 — will re-exhaust any small cap.
  2. Set a draft-PR CI policy. Full 3-OS only on ready_for_review / merge, not on every draft push. Drafts run Linux-only (already the push default). This is the single change that keeps spend near $0.
  3. Approve or revise ADR-0015 (quantized q5 default) — it's evidence-backed and I recommend accept; that unblocks PR #24 and the q5 stack.
  4. Land the P1-G3 stack in order (#18→#26 bottom-up, or squash-consolidate into 2–3 coherent merges to end the sprawl), each passing the now-affordable 3-OS gate.

Close P1

after unjam · P1-G3 + P1-G4
