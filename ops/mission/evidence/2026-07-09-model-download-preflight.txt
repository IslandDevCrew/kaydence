What changed
- Added a Rust-owned first_run_model_download_preflight Tauri command.
- The command returns a structured FirstRunModelDownloadPreflight with model id, task, lane, runtime, file, current first-run state/detail, availability, destination path, expected sha256, size, source count, source URLs, license, block reason, operator action, and proof requirement.
- The command is read-only: it uses the existing registry ModelDownloadPlan and the current AppSnapshot readiness state, and it does not fetch bytes or create model files.
- Screen Family 10 now renders a Review action for incomplete required models and shows the download preflight card from Rust-owned truth.

Honest boundary
- This is not the network downloader and not a progress bar.
- It deliberately keeps audit-network clean and blocks placeholder hashes/sources.
- The actual fetch/progress path is still a future critical decision path requiring ADR/operator review and an allowlisted, toggled network surface.
