Scope:

  - `AsrRequest`
  - `AsrTranscript`

  - `AsrEngine` trait
  - `EngineLane` values for BYOK cloud, local GPU, and local CPU
  - `EngineStack` fallback runner
- Added transcript-to-`SessionEvent` mapping:
  - partials emit before `RawFinal`
  - raw final output is preserved verbatim
  - empty finals are rejected
  - high no-speech probability rejects likely hallucinated finals
- Added fallback behavior per ADR-0002 / engine AGENTS:
  - try BYOK cloud if configured
  - fall back to local GPU
  - fall back to local CPU
  - report terminal failure only after configured engines fail
- No model runtime dependency was added. Parakeet, Whisper, and BYOK adapters
  remain future implementation slices.
