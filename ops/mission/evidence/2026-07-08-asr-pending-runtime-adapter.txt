Kaydence ASR pending runtime adapter evidence
Date: 2026-07-08 23:22 CDT / 2026-07-09T04:22Z

Intent
- Replace the default runtime's empty ASR stack with an honest pending local-ASR
  adapter, so real hotkey captures persist audio and record a specific
  Recognize failure while Parakeet/Whisper adapters are still unimplemented.
- Preserve the no-fake-output rule: this does not synthesize transcripts,
  debug-recognize text, or pretend model inference exists.
- Thread first-run's selected ASR model/lane into the runtime diagnostic so
  history/debugging can explain which selected model is awaiting an adapter.

  - Expanded AllEnginesFailed to retain per-lane failure summaries.
  - Added PendingLocalAsrEngine and pending_local_asr_stack.
  - Added tests for detailed terminal failures and the selected-model pending
    adapter path.
- apps/desktop/src-tauri/src/pipeline/mod.rs
  - default_runtime_pipeline now uses pending_local_asr_stack instead of an
    empty EngineStack.
  - Added a regression proving the default runtime records AudioPersisted first,
    then a specific Recognize failure naming the selected ASR model.
- apps/desktop/src-tauri/src/lib.rs
  - HotkeyRuntime::new now accepts first-run state, extracts the selected ASR
    model/lane, and passes that context to the default runtime pipeline.
  - Added selected_asr_runtime_context_carries_model_and_lane.

Honest limits
- This does not implement Parakeet, Whisper, or BYOK inference adapters.
- This does not download model bytes or add a network path.
- This does not prove WER, latency, or first successful dictation.
- Runtime selection is captured at hotkey runtime startup; full hot-swapping on
  later model changes still belongs with the real adapter lifecycle.
