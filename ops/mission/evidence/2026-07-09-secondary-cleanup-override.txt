# Kaydence P1-P0-1 secondary cleanup override hotkey evidence

Timestamp: 2026-07-09T17:52Z

Scope:
- PRD P0-1 global hotkey.
- PRD P0-5 cleanup dial per-invocation override.
- `apps/desktop/src-tauri/src/hotkeys/AGENTS.md` secondary dial-override chord.

Implemented:
- Added shortcut roles for primary vs cleanup override runtime paths.
- Added `Shift+RightAlt` / `Shift+RightOption` parser for the secondary override chord.
- Desktop startup still treats primary registration as the readiness gate, but now tries to register the secondary Raw override chord alongside it.
- Runtime ignores mismatched release edges, so a primary release cannot end an override capture.
- Override captures apply `CleanupDial::Raw` only for that invocation; the next primary capture returns to the detected profile cleanup dial.
