Kaydence evidence: macOS frontmost-app detector
Date: 2026-07-08

Intent
- Replace the platform target resolver's macOS Unknown fallback with a real app-identity detector.
- Bind and re-check capture targets using only frontmost application bundle id and app name.
- Preserve the privacy invariant: do not read window titles, screen contents, or field contents.
- Fail closed to Unknown when System Events access fails or returns incomplete identity.

Changed
- apps/desktop/src-tauri/src/profiles/mod.rs
  - Added MacOsFrontmostAppDetector behind cfg(target_os = "macos").
  - Implemented frontmost app lookup through /usr/bin/osascript + System Events.
  - Parser accepts only "bundle-id<TAB>app-name" and rejects missing value / incomplete output.
  - platform_target_resolver now uses MacOsFrontmostAppDetector on macOS and UnknownFrontmostAppDetector elsewhere.

Live macOS evidence
- /usr/bin/osascript -e 'tell application "System Events"' -e 'set frontApp to first application process whose frontmost is true' -e 'set frontName to name of frontApp' -e 'set frontBundle to bundle identifier of frontApp' -e 'return frontBundle & tab & frontName' -e 'end tell'
  - PASS on this host: returned "com.openai.codex	Codex"
