Kaydence model download metadata UI evidence
Date: 2026-07-08

Intent
- Carry validated model download-plan metadata into AppSnapshot so first-run can
  explain missing local artifacts without frontend guesswork.
- Render download availability, size, and source count in the first-run ASR
  picker and required-model list.
- Keep React presentation-only: Rust computes availability; React only renders
  the fields.

Changed files
- apps/desktop/src-tauri/src/settings/mod.rs
  - Added download_available, download_size_mb, and download_source_count to
    FirstRunModelStatus and FirstRunAsrCandidate.
  - Updated serialization tests for the expanded first-run model/candidate
    contract.
- apps/desktop/src-tauri/src/lib.rs
  - First-run model mapping now copies ModelDownloadPlan metadata into the
    AppSnapshot rows.
  - Missing artifacts with a valid plan carry size/source metadata.
  - Missing artifacts without usable metadata remain Blocked and report zero
    download metadata.
  - Runtime tests assert both the downloadable-missing and blocked-metadata
    states.
- apps/desktop/src/App.tsx
  - Added the new snapshot fields to the TypeScript shapes.
  - Renders "MB / source count" for downloadable ASR candidates and required
    models.
