Safety and boundaries
- The installer requires a registered model id and a non-placeholder registry sha256.
- The selected source file is hashed before copy; checksum mismatch leaves the source untouched and does not create an active model artifact.
- Existing bad app-data artifacts are quarantined through the existing checksum mismatch path before replacement.
- The frontend never verifies, copies, or trusts model bytes; it opens a native file picker and sends the selected path to Rust.
- This adds a local file-open UI capability only. It does not add model download networking or any new app egress.
- Current source-tree registry entries still have TODO checksums/sources, so production readiness remains blocked until reviewed artifact metadata is landed.
