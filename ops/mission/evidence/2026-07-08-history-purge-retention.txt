What changed
- Added HistoryStore::purge_all.
- Added HistoryStore::sweep_retention and sweep_retention_before.
- recent_history now applies the Rust settings privacy.history_retention_days window before recovery/listing.
- delete_session_and_audio now removes matching app-data export files as well as safe app-data session audio.
- Added purge_history Tauri command.
- Added cockpit Purge All action with a confirm gate and backend-returned purge counts.

Safety and boundaries
- Purge removes SQLite session rows/events, shallow app-data sessions/ file entries, and shallow app-data exports/ file entries.
- Retention removes expired SQLite rows and their safe audio/export artifacts; fresh sessions remain.
- Filesystem cleanup is limited to Kaydence-owned app-data child directories.
- remove_owned_file removes regular file or symlink entries only; it does not recurse into directories.
- Existing single-session delete still refuses unsafe/external audio paths.
- The frontend does not choose filesystem paths, transform transcripts, or decide which files count as history.
- No network surface was added.
- Remaining history/recovery polish: audio playback, recovered-audio re-transcription once real ASR adapters land, and 3-OS validation.
