Kaydence evidence: focus binding before injection
Date: 2026-07-08

Intent
- Close the runtime P9 safety gap: do not inject committed text if focus moved after capture started.
- Fail closed when app identity is unknown; unknown is not a trustworthy delivery binding.
- Preserve finalized text in history while recording Held(FocusChanged) instead of calling the injector.

Changed
- apps/desktop/src-tauri/src/inject/mod.rs
  - Added FocusTarget for detected versus unknown app identity.
  - Added verify_focus_binding(bound, current), which succeeds only when both app identities are verified and app ids match.
  - Added unit coverage for same verified app, changed app, and unknown identity.
- apps/desktop/src-tauri/src/lib.rs
  - FinalizeCapture now re-resolves the frontmost target before delivery.
  - If delivery-time focus does not match the capture-start target, runtime records SessionEvent::Held { reason: FocusChanged } and skips TextInjector entirely.
  - Unknown capture/delivery targets also hold as FocusChanged.
