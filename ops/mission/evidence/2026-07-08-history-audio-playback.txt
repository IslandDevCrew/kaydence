What changed
- Added HistoryStore::audio_playback.
- Added play_history_audio Tauri command.
- Added cockpit Play action for history rows with audio.
- Enabled Tauri asset protocol for app-data sessions/** only.
- Added media-src CSP entries for asset: and http://asset.localhost so the native audio control can load scoped local WAVs.
- Enabled Tauri's protocol-asset feature. Cargo.lock now includes Tauri's http-range helper for local media serving.

Safety and boundaries
- Playback returns an asset only for a stored audio path that canonicalizes under app-data sessions/.
- Playback refuses unsafe, external, missing, non-file, or non-WAV paths.
- The frontend does not decide file safety and does not read arbitrary files; it asks Rust for a validated path and converts it with Tauri convertFileSrc.
- The asset protocol scope is limited to app-data sessions/**, not the full app-data directory or user filesystem.
- No app network surface was added; audit-network remains at 0 call sites.
- Remaining history/recovery polish: recovered-audio re-transcription once real ASR adapters land, and 3-OS validation.

Documentation checked
- Context7 Tauri v2 docs for convertFileSrc and asset protocol:
  convertFileSrc converts device file paths for WebView loading; asset: and http://asset.localhost must be allowed in CSP; app.security.assetProtocol must be enabled with a scoped allowlist.
