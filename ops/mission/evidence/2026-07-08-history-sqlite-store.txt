Kaydence SQLite history store slice
Date: 2026-07-08
Commit: pending at evidence capture

Intent
- Replace the history stub with a local SQLite store for P0-4.
- Persist every SessionEvent as an append-only JSON event stream.
- Maintain a query-friendly session summary with audio path, raw text, clean
  text, cleanup dial, injection method, held reason, and failure state.
- Preserve available text even when a session is held or failed.
- Keep this local-only; no telemetry, accounts, or network surface.

Implementation summary
- Added rusqlite with bundled SQLite, matching docs/ARCHITECTURE.md persistence
  direction and improving Windows handoff portability.
- Added HistoryStore::open, open_at, and open_in_memory.
- Added forward migration table, sessions table, session_events table, indexes,
  and PRAGMA user_version = 1.
- Added HistoryStore::record_event / record_events.
- Added HistoryStore::get_session, list_recent, and events_for_session.
- Added summary aggregation for multi-segment RawFinal/CleanFinal streams.
- Added state capture for Injected, Held, and Failed events.
