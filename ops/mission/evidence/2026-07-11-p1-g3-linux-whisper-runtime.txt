BUILD-HOST DEFECT FOUND
whisper.cpp's default `GGML_NATIVE=ON` translated this virtual ARM host into a
GCC target containing `fp16fml` but not the FP16 vector-arithmetic option needed
by `vfmaq_f16`. GCC correctly rejected it with:

  error: inlining failed in call to 'always_inline' ... vfmaq_f16(...):
  target specific option mismatch

`GGML_NATIVE=OFF` compiled successfully and produced the exact transcript, but
the fully portable ARMv8 baseline took 1500 ms and therefore failed Kaydence's
1200 ms LocalCpu assertion. That attempt is diagnostic, not a passing gate.

PASSING CAPABILITY-MATCHED ARM BUILD
The VM advertises `fphp`, `asimdhp`, and `asimddp`. The passing build kept native
autodetection off and selected those reviewed capabilities explicitly:

  GGML_NATIVE=OFF
  GGML_CPU_ARM_ARCH=armv8.2-a+fp16+dotprod

CMake cache and generated compiler flags:

  GGML_NATIVE:BOOL=OFF
  GGML_CPU_ARM_ARCH:STRING=armv8.2-a+fp16+dotprod
  CXX_FLAGS = ... -march=armv8.2-a+fp16+dotprod -std=gnu++17

Command:

  GGML_NATIVE=OFF \
  GGML_CPU_ARM_ARCH=armv8.2-a+fp16+dotprod \
  KAYDENCE_WHISPER_MODEL="$PWD/ggml-base.en.bin" \
  KAYDENCE_WHISPER_CLIP="$PWD/corpus_0.wav" \
