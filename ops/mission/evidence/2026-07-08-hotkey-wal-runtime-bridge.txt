Scope:
- Added audio::WalCaptureRuntime, the minimal runtime owner for one active
  app-data sessions/{ulid}.wav WAL file per dictation.
- StartCapture now opens and fsyncs an identifiable WAV/WAL header immediately.
- DiscardCapture now removes the short-tap WAL before downstream processing.
- FinalizeCapture now patches/fsyncs the WAL header and produces an
  AudioPersisted SessionEvent payload for downstream history/engine wiring.
- Added a tiny CaptureCoordinator::reset hook so a runtime start failure cannot
  leave the pure hotkey state machine stuck in Capturing.
- Replaced console-only global-shortcut action logging with a shared
  HotkeyRuntime that maps RightAlt press/release/tail-tick into the WAL runtime.
- Added a tail-timer tick thread so a valid push-to-talk release actually
  finalizes after the 300 ms tail buffer.
