## Changes

- Added `HistoryStore::delete_session_and_audio`.
  - Deletes the SQLite session row.
  - Removes the audio file only when the recorded path canonicalizes under the
    app-data `sessions/` directory.
  - Refuses relative, missing, non-file, symlink-escaped, and external paths.
- Added the `delete_history_session` Tauri command.
  - Opens the app-data history store.
  - Runs the backend-owned delete operation.
  - Returns the refreshed bounded recent history list to the frontend.
- Added a cockpit row-level Delete action.
  - React asks for confirmation, sends the session id, and renders the returned
    list.
  - React does not delete files, mutate SQLite, or transform history data.
- Updated mission state and continuation prompt to reflect that recent history is
  no longer read-only for single-session cleanup.
