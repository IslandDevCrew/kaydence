Kaydence model readiness recheck evidence
Date: 2026-07-08 local / 2026-07-09T04:16Z

Intent
- Let first-run setup re-scan app-data model artifacts after a user or build
  agent installs reviewed files, without requiring an app restart.
- Keep readiness authority in Rust. React only sends the recheck intent and
  renders the returned AppSnapshot.
- Reuse the startup model refresh path so manual recheck and app boot cannot
  drift apart.

- apps/desktop/src-tauri/src/lib.rs

  - Added RuntimeSnapshot::refresh_models and
    RuntimeSnapshot::refresh_models_from_app_data.
  - Tauri setup now calls the same refresh_models_from_app_data helper used by
    the command.

Honest limits
- This does not download model bytes and adds no network fetch.
- This does not add progress, cancellation, retry, or resume UI.
- This does not replace registry TODO hashes/sources with reviewed published
  artifacts.
- This does not implement Parakeet or Whisper inference adapters.
- This does not provide WER or latency evidence for real ASR output.
