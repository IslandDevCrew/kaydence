Kaydence evidence: macOS CGEvent Unicode fallback
Date: 2026-07-08

Intent
- Add the macOS keystroke-synthesis fallback under the same secure-field gate as AXSelectedText.
- Cover focused fields that are editable but do not expose AXSelectedText as settable.
- Keep the fallback layout-independent by posting Unicode text through CGEventKeyboardSetUnicodeString.
- Preserve the privacy gate by fixing an audit-network false positive instead of allowlisting local CoreGraphics FFI as network.

Changed
- apps/desktop/src-tauri/src/inject/macos.rs
  - MacOsTextInjector::caps now advertises KeystrokeChannel::MacOsEvent only when AX confirms an editable focused field.
  - synth_text re-checks the focused AX element and refuses secure/no-target focus before posting CGEvents.
  - Added CGEventCreateKeyboardEvent, CGEventKeyboardSetUnicodeString, and CGEventPost FFI.
  - Added UTF-16 chunking with tests for emoji/surrogate safety, multilingual roundtrip, and empty text.
- scripts/audit-network.sh
  - Narrowed the browser EventSource scan token to EventSource( so local Apple CGEventSourceRef types do not trip the network gate.
  - Verified the no-space fixed-string pattern avoids bash word-splitting in the existing grep argument builder.
