Kaydence recent history surface evidence
Date: 2026-07-08 23:28 CDT / 2026-07-09T04:28Z

Intent
- Surface the local SQLite history safety net in the cockpit so users/build
  agents can see persisted sessions, held text, and Recognize failures.
- Keep React presentation-only: Rust reads the database and returns serialized
  session rows; React renders them and sends only a refresh intent.
- Make the ASR pending-adapter failure visible to the UI through the same
  history path that protects audio and text.

Honest limits
- This is a read-only recent-history surface.
- This does not implement audio playback, export, purge/delete-all, retention
  sweep, or crash-orphan recovery UI.
- This does not auto-refresh during active dictation; users can refresh the
  visible recent list manually.
- This does not complete P1-P0-4 on all three OSes; CI/remote remain separate
  trust anchors once the remote is restored.
