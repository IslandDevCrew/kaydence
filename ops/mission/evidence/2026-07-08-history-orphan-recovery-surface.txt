## Changes

- Added `HistoryStore::record_recovered_audio`.
  - Records an `AudioPersisted` event for a recovered WAL path.
  - Records a `Failed { stage: Capture }` event explaining that audio was
    preserved after app exit before transcription.
  - Is idempotent for sessions that already have an audio path.
- Added `HistoryStore::session_has_audio` so recovery can skip already tracked
  sessions without rewriting known WAV files.
- Added `recover_history_audio` to the Tauri backend path.
  - `recent_history` now scans app-data `sessions/` before listing.
  - It parses ULID session ids from `{ulid}.wav`, patches recoverable WAL headers
    in place, and surfaces only files not already represented in SQLite.
  - Invalid filenames and unrecoverable WAV-like files are skipped and never
    deleted.
- The existing cockpit history strip now shows recovered audio automatically as a
  failed Capture session with the preserved audio path.
