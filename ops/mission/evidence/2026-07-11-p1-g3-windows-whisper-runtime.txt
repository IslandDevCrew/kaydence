BUILD BOUNDARIES FOUND AND CLOSED
1. The first real compile hit Windows CRC/data-write failures while the Mac
   host had only 101 MiB free. That attempt is invalid infrastructure evidence.
   `cargo clean` removed 34.3 GiB of disposable host Kaydence artifacts, and
   the npm cache cleanup restored enough headroom for a clean retry.
2. Current whisper.cpp explicitly rejects MSVC on ARM. The official Visual
   Studio Build Tools components were added:
   - Microsoft.VisualStudio.Component.VC.Llvm.Clang
   - Microsoft.VisualStudio.Component.VC.Llvm.ClangToolset
3. Native ARM64 clang-cl 19.1.5, Ninja 1.12.1, and the ARM64 MSVC linker were
   verified in one environment. The build used CMake 3.31.6-msvc6 and linker
   14.44.35228.0.
4. clang-cl needed C++ exceptions enabled (`CXXFLAGS=/EHsc`) for gguf.cpp.
5. The bundled whisper-rs-sys bindings contained glibc layout assertions and
   were invalid on Windows ARM64. Native libclang generated target-correct
   bindings instead; no source patch or downloaded model weight entered git.
