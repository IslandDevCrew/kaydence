Scope:
- Added `audio::vad` as the dependency-free speech-gating contract between the
  16 kHz audio boundary and the future engine feed.
- The gate accepts 16 kHz mono samples after WAL persistence. It does not write
  to WAL and does not own ASR; it only decides which samples are eligible for
  the engine.
- Default timing matches the audio invariants:
  - 16 kHz sample rate
  - 512-sample frames
  - 250 ms pre-roll = 4,000 samples
  - 300 ms end-silence window = 4,800 samples
- `VadDetector` is a trait so the production Silero adapter can land later
  without changing the gate behavior.
- `EnergyVad` exists only as a deterministic local/test detector. It is not
  represented as the production Silero model.
