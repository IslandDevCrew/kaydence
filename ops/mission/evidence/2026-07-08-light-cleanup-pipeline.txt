Implementation summary
- Added cleanup::CleanedTranscript.
- Added cleanup::clean_text:
  - Raw returns the input untouched.
  - Light applies deterministic filler removal, adjacent repeated-word dedupe,
    spoken punctuation, spoken newlines, capitalization, final punctuation, and
    simple self-correction collapse.
  - Full currently uses the same deterministic floor without authoring; the
    profile rewrite/LLM pass remains a future adapter.
- Added cleanup::clean_final_event:
  - Raw emits no CleanFinal.
  - Light/Full emit SessionEvent::CleanFinal with the original SessionId.
- Updated TranscriptionPipeline to append CleanFinal immediately after RawFinal.
- Added TranscriptionPipeline::with_cleanup_dial for tests and future settings
  wiring.
