Slice: local history export under PRD P0-4

What changed
- Added HistoryStore::export_session.
- Added export_history_session Tauri command.
- Added a per-row Export action to the cockpit history list.
- Export writes backend-owned app-data exports/{session}.json and exports/{session}.txt.
- JSON contains schema_version, exported_ms, the HistorySession summary, and the ordered SessionEvent stream.
- Text contains a readable local session export with target app, status, audio path, event count, raw transcript, and clean transcript.

Safety and boundaries
- Missing sessions return exported=false and do not create an exports directory.
- Invalid session ids are rejected by the Tauri command before history touches disk.
- The frontend does not construct files, transform transcripts, mutate SQLite, or choose paths.
- Export path is fixed under the OS app-data directory; no user-supplied filesystem destination was introduced.
- No network surface was added.
- Remaining history/recovery polish: audio playback, purge/delete-all, retention sweep, recovered-audio re-transcription once real ASR adapters land, and 3-OS validation.
