Scope:
- Added rubato 1.x and audioadapter-buffers 2.x for drain-thread resampling.
  Cargo resolved rubato to 1.0.1 under the repo's Rust 1.80 baseline.
- Input config selection still prefers native 16 kHz PCM when the device offers
  it. If not, it falls back to a supported PCM input rate, preferring common
  device rates in this order: 48 kHz, 44.1 kHz, 32 kHz, then range max.
- The realtime cpal callback remains unchanged in spirit: downmix interleaved
  PCM to f32 mono and try_push into the lock-free ring buffer. It does not
  resample, allocate, lock, log, write files, or call ASR.
- The drain thread now owns the sample-rate normalization step. It passes
  16 kHz input straight through and uses a rubato fixed-input FFT resampler for
  every other native device rate before appending to the WAL.
- Resampled sessions flush a final zero-padded partial chunk on stop so the
  tail favors preserving the last syllable over trimming too aggressively.
- Ring capacity now follows the native input rate for a two-second buffer,
  while the WAL remains fixed at the existing 16 kHz contract.
