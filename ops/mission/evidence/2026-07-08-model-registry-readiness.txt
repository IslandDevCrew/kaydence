Kaydence model registry readiness slice
Date: 2026-07-08
Commit: pending at evidence capture

Intent
- Add a local-only model registry contract for Kaydence runtime artifacts.
- Parse models/registry.json as the source of truth for ASR, VAD, cleanup, and
  prediction model metadata.
- Verify local artifacts with SHA-256 before declaring them ready.
- Fail closed while registry checksums are TODO placeholders.
- Do not add any download path or network surface in this slice.

Implementation summary
- Added apps/desktop/src-tauri/src/models/mod.rs.
- Added ModelRegistry::load/from_json with schema-version and duplicate-id
  validation.
- Added ModelEntry::artifact_path with plain-filename enforcement to reject
  path traversal and nested/absolute artifact paths.
- Added ModelEntry::verify_artifact:
  - returns PlaceholderChecksum when sha256 is missing or not 64 hex chars;
  - returns Missing only after checksum metadata is usable;
  - streams file content through SHA-256 and returns Ready only on exact match;
  - returns ChecksumMismatch on mismatch.
- Added first-run helper for recommended ASR/VAD artifact verification.
- Added sha2 dependency for local hashing only.

Registry state observed
- models/registry.json parses successfully.
- Recommended first-run candidates include:
  - ASR: parakeet-v3, whisper-large-v3-turbo
  - VAD: silero-vad
- Current registry checksums remain TODO placeholders, so model readiness fails
  closed by design until integration fills real artifact hashes.
- Current model sources are also TODO placeholders; no download behavior was
  introduced.
